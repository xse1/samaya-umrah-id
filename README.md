# نظام سمايا لإصدار بطاقات المعتمرين

نسخة تعمل بالكامل داخل المتصفح على GitHub Pages دون خادم Python.

[افتح النظام](https://xse1.github.io/samaya-umrah-id/)

- إدارة المعتمرين وإصدار بطاقات CR80 وA4 بصيغة PDF.
- قراءة الجوازات والصور محليًا باستخدام Tesseract.js وOpenCV.js، مع مراجعة بشرية قبل الاعتماد.
- حفظ مستقل داخل كل متصفح باستخدام IndexedDB؛ لا تُرسل بيانات الجوازات إلى GitHub أو خدمة OCR خارجية.
- نسخ احتياطي واستعادة، مع تشفير اختياري بكلمة مرور، لنقل البيانات بين الأجهزة.

## المصدر الكامل

[تنزيل المصدر كاملًا](./samaya-source.zip). يحتوي أرشيف المصدر على React وTypeScript وقالب البطاقة المشترك ومحركات المتصفح، وكذلك نسخة FastAPI وSQLite المحلية وملفات تشغيل Windows ودليل البناء والاختبارات.

المصدر منفصل عن ملفات الموقع الجاهزة لتسهيل رفعه عبر واجهة GitHub. لا توجد بيانات معتمرين أو جوازات في الأرشيف أو في ملفات الموقع.

## الاستخدام

افتح الموقع، واضبط الفندق والمشرف وارفع QR الفندق من الإعدادات. ارفع الجواز وراجع الاسم العربي ورقم الجواز والصورة. صحح البيانات وأكد المراجعة ثم اعتمد البطاقة. اطبع PDF بالحجم الفعلي 100٪.

كل جهاز ومتصفح مستقل. صدّر نسخة احتياطية من الإعدادات لنقلها أو حفظها؛ حذف بيانات الموقع من المتصفح قد يحذف السجلات المحلية. الاستعادة تستبدل البيانات الحالية بعد التأكيد.

تحتاج الزيارة الأولى وتنزيل محركات القراءة إلى إنترنت. جودة OCR مرتبطة بصورة الجواز وتحتاج مراجعة. تفاصيل البناء والتشغيل والاختبارات داخل أرشيف المصدر.

يضم أرشيف المصدر جميع الملفات البرمجية وسكربتات تنزيل النماذج. ملفات النماذج التشغيلية مرفوعة في جذر المستودع، ولا تُكرر داخل الأرشيف لتقليل الحجم.
